## 통과

`node --test tests/*.test.mjs`: **8개 통과 / 0개 실패**.

- Canonical CHAT_MESSAGE에서 계정 ID, 닉네임, 메시지 추출.
- 다른 방송, 귓속말, 20초보다 오래된 복구 메시지 제외.
- 실제 로컬 WebSocket 연결에서 API 키 헤더, protocol 4 구독, 이벤트 ID 중복 제거.
- 전역 seq 점프를 누락으로 오인하지 않음.
- 명시적 gap 이후 과거 이벤트 복구, 재연결 resume, 중지 후 재접속 차단.
- 채팅 시 정지, 동일 계정 닉네임 변경, 말풍선 종료 후 걷기 재개.
- 좁은 화면에서 말풍선 사각형 겹침/화면 밖 배치 방지.
- 5,000명 채팅 입력에서 새우/대기열 상한 유지, 비활동 만료.
- 숨김 계정/단어 설정을 기존 말풍선에 반영.
- 잘못된 설정 거부, 공개 응답에서 API 키 제외.
- 프로그램 HTTP → 외부 코어 WS → SSE 전체 경로 테스트.
- SSE 채팅 수신, 제재 이벤트 숨김, 화면 비우기, 종료.
- 설정 파일 저장 후 프로세스 재시작 시 설정 복원.

내장 코어 TypeScript 변환 완료. 컴파일된 코어를 직접 실행해 `/livez` 200 응답 확인.

서버/관리 화면/오버레이 JavaScript 문법 검사 통과.

승인한 새우 PNG 원본 그대로 포함. RGBA alpha 범위 0~255로 투명 배경 확인.

## 미확인

- 실제 SOOP 방송 접속: 사용자 방송 ID와 실제 네트워크에서 확인 필요.
- Windows .bat 실행과 OBS/프릭샷플러스 내부 표시: 해당 환경에서 확인 필요.
- 브라우저 시각 검증: 현재 실행 환경의 Cloud Browser가 localhost 접근을 `ERR_BLOCKED_BY_CLIENT`로 차단했고, 로컬 Chromium 설치도 정상 파일 다운로드에 실패했습니다. 관리 화면과 Canvas 렌더링을 실제 브라우저에서 검증했다고 주장하지 않습니다.
- 좌우 방향별 4프레임 걷기와 8종 포즈 아틀라스를 사용합니다. 실제 방송 프로그램의 프레임 재생은 별도 확인이 필요합니다.

프로그램은 모든 채팅을 표시하는 로그 뷰어가 아닙니다. 메시지가 몰리면 읽기와 화면 공간을 위해 동일 시청자 최신 메시지로 갱신하며, 대기 시간이 12초를 넘는 메시지는 제외합니다.
