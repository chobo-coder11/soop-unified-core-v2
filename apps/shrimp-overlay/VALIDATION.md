## 미확인

- 실제 SOOP 방송 접속: 사용자 방송 ID와 실제 네트워크에서 확인 필요.
- Windows .bat 실행과 OBS/프릭샷플러스 내부 표시: 해당 환경에서 확인 필요.
- 브라우저 시각 검증: 현재 실행 환경의 Cloud Browser가 localhost 접근을 `ERR_BLOCKED_BY_CLIENT`로 차단했고, 로컬 Chromium 설치도 정상 파일 다운로드에 실패했습니다. 관리 화면과 Canvas 렌더링을 실제 브라우저에서 검증했다고 주장하지 않습니다.
- 좌우 방향별 4프레임 걷기와 8종 포즈 아틀라스를 사용합니다. 실제 방송 프로그램의 프레임 재생은 별도 확인이 필요합니다.

프로그램은 모든 채팅을 표시하는 로그 뷰어가 아닙니다. 메시지가 몰리면 읽기와 화면 공간을 위해 동일 시청자 최신 메시지로 갱신하며, 대기 시간이 12초를 넘는 메시지는 제외합니다.

## v1.2.0 검증

30/60fps 시뮬레이션에서 이동거리와 보행 위상 일치, 포즈 경계·순환 시 보간 연속성, 캐시 메모리 상한과 재사용, FPS 측정과 중단 후 초기화 검증을 추가했습니다. 실제 GPU 성능이나 60fps 유지 여부를 측정한 것은 아닙니다.

OGQ 109 패킷 → 내장 코어 디코더 → 오버레이 이벤트 정규화, 전용 WS 구독과 SSE 전달, 텍스트 없는 OGQ 이벤트, WebP 실패 시 PNG 대체, URL 제한, 이미지 로딩 중 큐 대기와 기존 텍스트 말풍선 크기 변경을 검증했습니다. 모의 이미지 요소 600번 갱신 시 같은 요소를 유지하고 src는 한 번만 설정하는 것을 확인했습니다. 실제 브라우저에서 움직이는 OGQ 프레임을 육안 검증한 것은 아닙니다.

숨김 계정 ID는 사용자 확인으로 정상 동작하는 것으로 정리했으며 이번 변경에서 동작을 변경하지 않았습니다.

추가 동작의 감속 후 시작, 20종 자율 행동 분포, 반응 종료 후 말하기 복귀, 행동 시작·끝의 회전/신축 곡선도 검증했습니다.

캐릭터 선택 값 검증, 선택 저장 후 재시작, 오리 이미지 HTTP 전달과 투명 PNG 확인을 추가했습니다. 실제 브라우저의 오리 애니메이션은 미검증입니다.
