# 캐릭터 채팅마을 v1.4.0

방송 화면 아래를 산책하는 귀여운 캐릭터들이 시청자 채팅에 맞춰 멈추고 이름표와 말풍선을 표시하는 로컬 방송 오버레이입니다. 방향별 걷기 프레임과 표정 포즈, 부드러운 보간 및 20종 자율 동작을 사용합니다.

## v1.4.0 새 기능

꾸미기에서 새우·오리·참새·물개·휴지·보라색 꿀벌·감자튀김·장미·고릴라·뿔달린 보라 문어·티백·다람쥐·올챙이 중 선택하고 저장하세요. 시청자 캐릭터와 배경 산책 캐릭터가 함께 바뀝니다. 캐릭터별 이동 보폭과 흔들림을 달리했습니다.

추가 동작: 인사, 점프, 졸기, 웃기, 두리번, 기지개, 깡충, 갸웃, 꾸벅, 끄덕, 좌우 흔들기, 응원, 놀라기, 빼꼼, 통통, 팔랑, 까딱, 꼬물, 발돋움, 쉬기. 별도 신규 그림 20장을 뜻하지 않으며, 포즈 그림과 이동·회전·신축을 조합한 동작입니다. 자율 동작 간격은 2~20초 기준이며 캐릭터별로 분산됩니다. 걷다가 먼저 감속한 뒤 동작하며, 채팅 반응은 한 번 재생한 뒤 말하기로 이어집니다.

캐릭터 밝기는 기본 114%로 밝게 조정했고 80~140%로 바꿀 수 있습니다. 이름표/말풍선 크기·여백·모서리·테두리·색·투명도, 글씨체와 두께도 설정합니다.

인원이 많으면 성능 모드를 ‘가볍게’로 설정하세요. 선택한 캐릭터 이미지만 불러오고 텍스처와 글자 폭을 재사용하며, 숨겨진 관리 화면 미리보기는 일시 정지합니다. 이 모드는 그림 해상도를 낮추며 모션 속도를 낮추지 않습니다. 실제 FPS는 OBS 설정과 PC 성능에 영향을 받습니다.

SOOP OGQ는 움직이는 WebP를 우선 사용하고 없으면 정적인 PNG로 대체합니다. 관리 화면에 정적/움직이는 OGQ 테스트 버튼이 있습니다.

## Windows 실행

1. ZIP을 폴더에 완전히 압축 해제합니다. 압축 파일 안에서 직접 실행하지 마세요.
2. Node.js 22.13 이상이 필요합니다. Node.js 24를 권장합니다.
3. `start.bat`를 실행합니다. 브라우저에서 관리 화면이 열립니다.
4. SOOP 방송 **ID**를 입력하고 `방송 연결하기`를 누릅니다. 닉네임이 아니라 방송국 주소의 ID입니다.
5. 기본 `내장 코어`에서는 SOOP Unified Core v2.6의 Native provider를 자동 실행합니다. Java나 npm 설치가 필요 없습니다.
6. OBS 브라우저 소스에 `http://127.0.0.1:17840/overlay`를 넣습니다. 너비/높이는 방송 캔버스와 같게 설정하세요. 예: 1920×1080.
7. 종료는 `stop.bat` 또는 실행 창에서 Ctrl+C입니다. 관리 화면의 연결 중지는 프로그램을 계속 켜 둡니다.

관리 화면: http://127.0.0.1:17840

방송 오버레이: http://127.0.0.1:17840/overlay

관리 화면의 미리보기 배경은 방송 소스에 포함되지 않습니다. 실제 오버레이는 투명합니다. 기본적으로 이름 없는 새우 6마리가 산책하고, 채팅하는 시청자가 늘어나면 이름 없는 새우가 줄어듭니다. `처음 산책하는 새우`를 0으로 설정하면 채팅한 시청자만 표시합니다. `미리보기 재생`이나 `새우에게 말시키기`로 화면을 테스트할 수 있습니다. 미리보기 재생은 실제 방송 연결을 중지합니다. 테스트와 미리보기 메시지는 열린 방송용 오버레이에도 표시되므로 방송 전에 사용하세요.

## 외부 코어 연결

이미 실행 중인 SOOP Unified Core가 있으면 `외부 코어`를 선택합니다.

- 예시: `ws://127.0.0.1:8080/v1/ws`
- 원격 TLS 코어: `wss://호스트/v1/ws`
- 코어에 `SOOP_API_KEY`가 설정되어 있으면 관리 화면에서 API 키를 입력합니다.
- 키는 로컬 설정 파일에 저장되며 오버레이 주소나 이벤트 스트림으로 전송되지 않습니다.
- 방송 ID, 코어 주소를 바꾸고 다시 연결하면 이전 새우는 비워집니다.

## 프릭샷플러스

현재 설치 버전의 웹/브라우저 주소 소스 지원을 확인한 뒤 같은 주소를 넣으세요. 이 버전은 OBS 브라우저 소스를 목표로 제작했고, 프릭샷플러스에서의 직접 동작은 검증하지 않았습니다. 웹 주소 소스가 없을 경우 창 캡처하면 투명 배경이 유지되지 않으므로 같은 사용 경험을 보장하지 않습니다.

## 동작

- 계정 ID에 따라 같은 방송 안에서 같은 새우를 사용합니다. 닉네임이 바뀌어도 이름표만 갱신됩니다.
- 계정 ID가 없는 이벤트는 닉네임을 대체 키로 사용합니다.
- 색상과 시작 위치는 계정 키에 따라 결정됩니다.
- 크기, 속도, 새우 수, 말풍선 수와 시간, 글자 크기, 아래 여백을 조절할 수 있습니다.
- 채팅 중에는 멈추고, 말풍선이 사라지면 다시 걷습니다.
- 가까운 말풍선은 최대 세 높이로 배치합니다. 공간이 없으면 제한된 대기열에 넣습니다.
- 같은 시청자의 연속 채팅은 최신 메시지로 갱신합니다. 연속 유지 시간은 제한합니다.
- 채팅 폭주 시 최신 시청자별 메시지 중심으로 표시합니다. 모든 채팅 표시를 보장하지 않습니다.
- 활동이 없는 새우는 설정한 시간이 지나면 사라집니다.
- 저장한 계정/단어 숨김과 코어의 mute/kick/blind_kick 이벤트를 반영합니다.
- 재연결 시 protocol 4 resume/gap을 처리합니다. 전역 seq 숫자 점프를 누락으로 오인하지 않습니다.
- 20초보다 오래된 복구 메시지는 화면에 표시하지 않습니다.
- 채팅 HTML은 실행되지 않습니다. Canvas와 textContent로 표시합니다.

## 소스 실행 / 내장 코어 생성

이 디렉터리가 SOOP Unified Core 저장소의 `apps/shrimp-overlay`에 있다면:

```sh
node build-core.mjs
node launch.mjs
node --test tests/*.test.mjs
```

내장 코어 생성은 저장소의 현재 `src`를 Node 내장 TypeScript 변환기로 컴파일합니다. ZIP에는 컴파일한 코어가 포함됩니다. 선택 provider는 기본 OFF이고 Native provider만 실행합니다.

내장 코어 원본 커밋: `a4e5c9f6e7fb0480a4de323c8e8cd8484ceb1a5d` (v2.6.0).

`ws` 8.18.0은 `vendor/ws`에 포함되어 있습니다. MIT 라이선스를 함께 배포합니다.

포트 변경: 실행 전에 `SHRIMP_PORT` (관리/오버레이), `SHRIMP_CORE_PORT` (내장 코어)를 설정하세요. 기본값은 17840, 17841입니다. 같은 PC에서 방송 프로그램을 실행하는 로컬 사용을 전제로 127.0.0.1에만 바인딩합니다.

검증 결과와 한계는 `VALIDATION.md`를 확인하세요. 실제 SOOP 방송 접속, Windows 실행, OBS/프릭샷플러스 내부 동작은 해당 환경에서 별도로 확인해야 합니다.

## v1.1.0 꾸미기 업데이트

좌우 방향별 4프레임 걷기, 가속·감속 및 정지 후 방향 전환을 추가했습니다. 인사, 점프, 웃기, 졸기 반응을 사용합니다. 말풍선과 이름표는 캐릭터 반응 위치를 함께 따라갑니다. 말풍선은 머리 가까운 한 줄에 배치하며, 공간이 없으면 대기합니다. 긴 연결선은 짧은 꼬리로 변경했습니다.

주아체·개구체를 로컬로 포함해 인터넷 없이 사용할 수 있습니다. 기본 글씨체도 선택할 수 있습니다. 이름 글자 크기, 가로·세로 여백, 최대 너비, 둥글기, 테두리, 위치, 불투명도와 색상, 말풍선 너비·줄 수·여백·테두리·간격·색상을 설정합니다. 저장 버튼을 누르면 기존 말풍선도 다시 배치합니다. 방송 연결 설정은 유지됩니다.

업데이트: 기존 프로그램을 stop.bat로 종료하고 새 ZIP을 별도 폴더에 풉니다. 설정을 유지하려면 이전 폴더의 data/settings.json을 새 폴더의 같은 위치에 복사한 후 start.bat를 실행합니다. OBS 브라우저 소스는 새로고침합니다.

## v1.2.0 — 걷기 성능과 OGQ

걷기 포즈를 이전에는 기본 속도에서 초당 약 3회 교체했습니다. 이동 거리 기반 보폭을 줄이고 포즈 사이를 매 렌더 프레임에 보간합니다. 색상 필터와 이미지 축소는 32MiB 상한의 캐시에 저장합니다. 투명 화면 전체 대신 새우·말풍선이 있는 영역만 지웁니다. 관리 화면에서 미리보기가 화면 밖에 있으면 그리기를 쉽니다. 미리보기 아래에 실제 관측 FPS와 평균 그리기 시간이 표시되며, 이는 OBS의 출력 FPS와 별개의 값입니다. 실제 PC의 GPU/브라우저 설정에 따라 프레임률은 달라집니다.

OGQ_EMOTICON 전용 이벤트를 구독하고 내장 코어에서 발신자 ID·닉네임을 제공합니다. 외부 코어의 기존 userInfo/color 필드도 읽습니다. 텍스트가 없는 이모티콘 이벤트도 새우를 생성합니다. 움직이는 WebP를 먼저 시도하고 없으면 PNG를 표시합니다. 이미지 요소를 유지하므로 화면을 갱신할 때 애니메이션을 초기화하지 않습니다. 이미지 로딩 동안 표시 시간을 소비하지 않고 대기하며, 끝내 로드되지 않으면 실패 안내를 표시합니다. 이모티콘 크기는 32~160px로 설정합니다. 정적/움직이는 OGQ 테스트 버튼을 제공합니다. OGQ 파일 자체는 패키지에 포함하지 않고 SOOP OGQ 이미지 주소로 불러옵니다.

범위: OGQ 전용 이벤트와 일반 유니코드 이모지. 일반 채팅의 /이름/ 형태인 별도 시그니처 이모티콘은 아직 이미지로 변환하지 않습니다. 모든 OGQ 상품의 실제 CDN 접근 및 OBS 내 애니메이션은 미검증입니다.

참고한 원본: https://github.com/getCurrentThread/soopapi/blob/develop/lib/src/main/java/com/github/getcurrentthread/soopapi/event/model/OGQEmoticonEvent.java ; 정적 이미지 https://ogqmarket.sooplive.com/emoticon/64b1213dfbb7b ; 움직이는 이미지 https://ogqmarket.sooplive.com/emoticon/646e3b2843650 .

동작: 산책 중 인사·점프·졸기·웃기·두리번거리기·기지개·작은 깡충·갸웃을 섞습니다. 먼저 감속해 멈춘 후 행동 시간을 시작하며, 행동의 처음과 끝에 부드러운 곡선을 적용하고 포즈 사이를 보간합니다. 채팅 반응은 한 번 후 말하는 자세로 돌아오며 OGQ 로딩 대기 후 실제 말풍선이 표시될 때 시작합니다. 새 동작 일부는 기존 포즈의 미세한 회전·신축으로 표현하며 개별 팔다리 리깅 애니메이션은 아닙니다.

## v1.3.0 — 캐릭터 선택

꾸미기의 캐릭터 종류에서 말랑 새우와 손그림 아기오리를 선택합니다. 선택한 종류는 전체 화면의 모든 시청자 캐릭터에 적용하고 저장·재시작 후에도 유지합니다. 오리는 손그림 스타일의 투명 16프레임 포즈/걷기 아틀라스를 사용합니다. 기본 자세·인사·말하기·점프·졸기·웃기와 우측/좌측 걷기를 포함합니다. 오리는 새우보다 짧은 보폭과 작은 뒤뚱거림을 적용합니다. 새우 또는 오리에 관계없이 이름표·말풍선·OGQ·필터·속도·크기 설정을 함께 사용할 수 있습니다. 사용자가 새 이미지 파일을 업로드하는 기능과 시청자별 서로 다른 캐릭터 선택은 이번 버전에 포함하지 않습니다.
