01

방송 연결

연결할 SOOP 방송을 알려 주세요.

닉네임 대신 방송국 주소에 있는 ID를 입력해 주세요.

SOOP Unified Core가 함께 실행돼요.
별도로 코어 프로그램을 켤 필요가 없어요.

OBS 브라우저 소스에 넣고 화면 크기와 맞춰 주세요.
프릭샷플러스는 웹 주소를 표시하는 소스가 있으면 같은 주소를 사용하세요.

방송에 넣는 방법
  1. 이 프로그램을 켜 둡니다.
  2. OBS에서 소스 추가 → 브라우저를 선택합니다.
  3. 위 주소를 넣고 너비 1920, 높이 1080으로 설정합니다.
  4. 소스를 방송 화면 위에 놓습니다. 배경은 자동으로 투명합니다.
  5. ‘소스가 보이지 않으면 종료’는 끄는 것을 권장합니다.

전체 화면 크기로 넣어야 말풍선이 위쪽에서 잘리지 않아요. 방송 해상도가 다르면 같은 크기로 맞춰 주세요.
