# 울산큰고래 × 마병대4 후원 작전실

엑셀에 누적된 마병대4 1~4일차 후원 데이터와 SOOP Unified Core v2 실시간 donation 이벤트를 함께 보는 정적 대시보드입니다.

## 로컬 실행

`index.html`을 정적 파일 서버로 열어 주세요. `file://`로 열면 `data.json` 로딩이 제한될 수 있습니다.

## 실시간 연결

화면 위 API 주소에 SOOP Unified Core의 공개 HTTPS 주소를 입력합니다. 대시보드는 `/v1/ws`에 연결하여 스트리머 `bach023`의 `donation`, `MISSION`, opcode `121` 이벤트를 구독합니다. 브라우저가 연결된 동안 받은 기록은 해당 브라우저의 localStorage에 저장됩니다.

SOOP Unified Core는 Node.js 22 이상이 필요합니다. 서버는 브라우저의 WSS 접속을 받을 수 있는 HTTPS 주소여야 합니다. 브라우저 클라이언트는 임의의 API key 헤더를 붙일 수 없으므로 dashboard 공개 연결에는 `SOOP_API_KEY`를 비워 둬야 합니다. 이 경우 읽기 전용 API도 공개되므로 서버 방화벽과 rate limit을 고려하세요. Core의 write API는 기본 비활성 상태로 유지하세요.

## 데이터 정확성

엑셀 원본 거래 423건의 상세 합계는 123,548개입니다. 검증표에 기록된 1~4일차 공식 합계는 140,733개이고, 세부 내역과의 17,185개 차이는 특정 후원자에게 임의 배분하지 않았습니다. 랭킹과 거래 목록은 상세 확인 내역 기준입니다.

Core가 `donation`으로 정규화한 이벤트만 실시간 합계에 반영합니다. 미확인 opcode 또는 수량이 없는 이벤트는 후원 합계로 추측하지 않습니다.
