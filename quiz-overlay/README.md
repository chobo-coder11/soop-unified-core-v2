# SOOP Quiz Overlay — draft 0.1.0

가벼운 Windows 방송용 퀴즈 진행 도구 초안입니다. `soop-unified-core-v2`의 WebSocket `CHAT_MESSAGE` 이벤트를 이용합니다.

## 핵심 흐름

1. Unified Core 실행 (`ws://127.0.0.1:8080/v1/ws`)
2. EXE 실행 후 SOOP 스트리머 ID 입력 → 연결
3. 참가 모집 시작 → 시청자는 `!참여`
4. 참가 마감 후 등록된 ID의 유효 답안만 판정
5. 문제 공개 → 아직 답변 불인정
6. 진행자가 `정답 입력 START` → 그 순간의 마지막 global `seq` 이후 답변만 인정
7. 답변 마감 → 자동으로 다음 화면으로 넘어가지 않음
8. 진행자가 정답 공개 → 결과 확인
9. 진행자가 다음 문제

## 문제 모드

- 객관식: `!1`, `!2`, ...
- 주관식: `!정답 서울`
- OX: `!O`, `!X`
- 숫자: `!숫자 2500` 또는 `!2500`

## 판정/점수

- 전체 정답자
- 선착순 N명
- 전체 정답 + 선착순 보너스
- 답변 정책: 첫 답변만 / 마지막 답변 인정
- 닉네임 표시는 항상 `닉네임(ID)`
- TOP10: 맞힌 개수 / 점수 / 최고 연속 정답

## 정확도

- 선착순 순서는 Unified Core downstream의 global `seq`를 1차 기준으로 사용합니다.
- START 시점의 마지막 `seq`를 gate로 저장하여 미리 입력한 답안을 차단합니다.
- `gap` / `resume_unavailable`을 감지하면 진행자 화면과 방송 레이어에 정확도 경고를 띄웁니다.
- 참가 모집 중에는 `!참여`/`!취소`만 처리하고, 모집 마감 후에는 등록된 참여자의 현재 문제에 유효한 답안만 저장합니다.
- 답변 접수 중 소켓이 끊기면 조용히 결과를 계속 만들지 않고 해당 문제를 안전하게 마감하고 정확도 경고를 남깁니다.

## 프릭샷 브라우저 URL

- 메인 퀴즈: `http://127.0.0.1:8765/overlay/quiz`
- TOP10: `http://127.0.0.1:8765/overlay/ranking`

두 URL은 완전히 분리되어 있어 원하는 위치/크기로 각각 배치할 수 있습니다.

## Windows 직접 빌드

`build_windows.bat` 실행 후 `dist\SOOP-Quiz-Overlay.exe` 생성.
